## RNAseq Isoform Expression
This [script](../cbioportal_etl/scripts/rna_merge_isoform_expression.py) uses the [generic assay](https://docs.cbioportal.org/file-formats/#generic-assay-data-file) format to load isoform data generated by RSEM.
It requires a cbio_manifest with isofrom data, currently possible in [this dbt branch](https://github.com/d3b-center/d3b-dbt-study-transforms/tree/feature/mb-add-rna-isoform).
It also required that key `RSEM_isoform` be added to `dl_file_type_list` for proper file downloads in hte json config.
Example run:
```sh
python3 ~/tools/kf-cbioportal-etl/cbioportal_etl/scripts/rna_merge_isoform_expression.py -t ../cbio_file_name_rna_isoform.txt.tsv  -r RSEM_isoform -sc pbta_medullo_subset_config.json
```

## DNAseq SV
In cBio, SV format covers both DNAseq SV calls and RNAseq fusions.
The proposed process has been refactored to have a [wrapper script](../cbioportal_etl/scripts/process_sv_data.py) run one or both of [RNAseq fusion](../cbioportal_etl/scripts/convert_fusion_as_sv.py) and [annotSV](../cbioportal_etl/scripts/annotsv_to_cbio_sv.py) transformation.
RNAseq fusion has not changed in command execution.
cbio manifest for DNA SV requires entries created as in [this dbt branch](https://github.com/d3b-center/d3b-dbt-study-transforms/tree/feature/mb-ad-dna-sv).
annotSV (DNA SVs) is new. Example run: 
```sh
python3 ~/tools/kf-cbioportal-etl/cbioportal_etl/scripts/annotsv_to_cbio_sv.py -t cbio_file_name_id_w_sv.txt
```
Example combined run:
```sh
python3 ~/tools/kf-cbioportal-etl/cbioportal_etl/scripts/process_sv_data.py -t cbio_file_name_id_w_sv.txt -f annofuse_filtered_fusions_tsv -m kfprod
```
